使用说明

  1. 批量导入

    支持 CSV（可带 email,password,twofa 表头）、JSON 数组与邮箱----密码----2FA 文本。密码中包含逗号时，请使用 CSV 引号或 JSON。

  2. 授权与状态检查

    选中账号，点击批量授权。后端逐个建立隔离 HTTP 会话，提交邮箱、密码和本地 TOTP，完成网页登录回调后读取 /api/auth/session。每个账号最多等待 7 分钟，支持停止队列。额外验证会报告失败。已有 Session 会先向服务器检查，有效则显示“跳过重复授权”。确认失效后才重新登录，遇到 HTTP 403、429 或服务异常会停止该账号的授权。检查状态复用已保存的 Cookie。

  3. 套餐与 Session

    登录成功后读取实际会话和套餐。套餐接口属于网页内部接口，可能变化，读取失败显示未知。导出文件保留 /api/auth/session 原始 JSON。单账号导出对象，多账号导出数组。Cookie 加密保存在本机供状态检查复用。

  4. 手机验证

    授权和检查状态时读取账号手机信息。接口明确返回验证状态时显示已验证或未验证；返回手机号时显示已关联；未返回证据或查询失败时显示未知。历史是否收过短信验证码可能无法查询，详情提供本次查询依据。

  5. 本机存储

    密码、2FA 和会话使用 AES-256-GCM 加密保存。data 目录包含密钥和加密数据库，需一起保管。导出的 JSON 含登录凭据，请妥善保存。
